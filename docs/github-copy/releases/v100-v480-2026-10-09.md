# Godox Firmware Mods · V100F + V480F

## 中文

项目更名为 **Godox Firmware Mods｜神牛闪光灯固件修改项目**。这次发布只提供 **V100F 与 V480F** 两款，均以官方 V1.03 固件为基线。作者已确认在自己的两台灯上刷入项目修改固件。

本次发布同时提供源码、可复现的补丁工具和现成 BIN 下载；两款 BIN 的字节数和 SHA 与此前交付版本一致，没有借这次发布加入新的未验证功能。

| 文件 | 实现内容 |
|---|---|
| `V100F_V1.03_SINGLE_S_LABEL_R7_EXPERIMENTAL.bin` | 机顶 Wi-Off 与从属 Receiver 主界面，旋钮直调主灯 TTL 曝光补偿或 M 功率；主控 Sender / 从属 Receiver 的原生 SU-1 手动功率界面，以及已覆盖的普通闪光路径；主控主灯 OFF 时副灯可独立发光；ZOOM 与下拉面板层级、字体修复 |
| `Godox_V480F_V1.03_rotary-direct_CANARY_v2.bin` | 机顶 Wi-Off 主界面直调 TTL 曝光补偿或 M 功率，保留原厂 0.1/0.3 步进和加速；菜单、无线角色和其他非目标页面沿用原厂逻辑 |

**两款文件不能混用，只适用于 F 后缀型号。V100 的副灯 TTL 未实现；V480 版没有从属 RX 直调，也没有 SU-1 扩展。**

V100 的可移植离线记录为 9,399 项功能检查，另有单独的 90 项 TTL 研究观测。V480 这次按单型号重跑，通过 12,489 项功能检查、746 次条件中断注入、1,386 项整镜像执行和 10 项补丁工具测试。两款源码都能精确重建对应的辅助代码。

作者“已刷入”的反馈没有附上机 SHA，也没有完整验收矩阵，因此与精确到下载文件的离线校验分开记录。文件仍带实验标签；完整的时序、光量、长时间稳定性和失败恢复流程，并不会因为刷入成功就自动视为完成。

在发布页下方 **Assets** 里选对应型号的 BIN，并核对 `SHA256SUMS.txt`。发布同时附 `RELEASE_MANIFEST.json` 和两款各自的补丁清单。原厂固件备份不随包分发。

## English

The project is now **Godox Firmware Mods**, currently covering **V100F and V480F only**, both based on official V1.03. The maintainer confirms project-modified firmware has been flashed onto both of their devices.

This release adds V480 source and reproduction tools alongside ready-made BIN downloads for both models. The images preserve the previously delivered bytes and hashes; no new firmware behavior is introduced by this publication.

- **V100F R7:** Wi-Off/RX direct main FEC/manual-power control; native Sender/RX manual SU-1 controls and covered normal firing routes; SUB-only normal exposure with Sender main OFF; ZOOM/drawer-layer and glyph repairs.
- **V480F v2:** Wi-Off main-screen direct FEC/manual-power control, preserving factory 0.1/0.3 steps and acceleration. Menus, wireless roles and other excluded screens retain original behavior.

**Do not interchange the files. F suffix only. SU-1 TTL is not implemented on V100; V480 v2 does not add RX direct adjustment or SU-1 features.**

V100's portable record contains 9,399 functional checks and 90 separate TTL observations. V480-only reruns passed 12,489 functional checks, 746 conditional interrupt injections, 1,386 whole-image executions and 10 patcher tests. Native helper source rebuilds match both recorded candidates exactly.

The maintainer's flashing report does not bind installed images to hashes or supply a full acceptance matrix, so it remains separate from exact file verification. Experimental labels remain; complete timing/energy/stability and failed-update recovery are not established by successful flashing alone.

Download the matching BIN under **Assets** and verify `SHA256SUMS.txt`. `RELEASE_MANIFEST.json` and model-specific patch manifests are included. Official backup images are not bundled.
