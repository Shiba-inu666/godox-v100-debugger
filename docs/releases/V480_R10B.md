# V480F v1.03r10b · 主控单灯页、从属直调与组别记忆

本次发布 **V480F V1.03** 的 R10b 实验版，文件名为 **`v480f-v1.03r10b.bin`**，与本地验证通过的候选内容一致。只适用于 V480F V1.03。

- 保留主控列表原厂长按 TTL/OFF/M、横向滑动调节和纵向滚动；单击 M/A–D 进入独立控制页。
- 单灯页提供 TTL/M、暂停/OFF 与恢复、加减和滑条，旋钮始终只调整当前灯的功率或 TTL 补偿。
- 主控 A–D 字块使用与原厂从属页一致的尺寸、字形、圆角和颜色。
- 机顶与从属 TTL/M 均支持旋钮直调，从属 TTL 补偿实时显示。
- 从属 A–E 选组确认后自动保存，切换机顶或主控模式再关机仍保留；恢复出厂设置回到 A。
