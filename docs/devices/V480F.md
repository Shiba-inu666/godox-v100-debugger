## 中文

**在普通机顶 Wi-Off 主界面，转动旋钮即可直接调节 TTL 曝光补偿或 M 手动功率**，无需先选中控件再按 SET。

| 项目 | 当前行为 |
|---|---|
| TTL | 沿用原厂曝光补偿，±3 EV，1/3 EV 步进；不改测光算法 |
| M | 沿用原厂功率函数与边界，保留 0.1 / 0.3 步进，保留快速旋转计数与加速路径 |
| 同一次输入 | 在目标状态下调完参数后，不会被重复当作 GUI 导航消费 |
| 非目标页面 | MENU、MODE、ZOOM、Sender、Receiver、锁屏、下拉和弹窗走原路径 |
| 不包含 | RX 直调、SU-1 扩展、新副灯 UI |

v2 修复了早期原型中重复消费输入、以及状态检查到写入之间的中断窗口。补丁保存/恢复 PRIMASK 与原选择器，复用原厂参数函数；不重写无线协议。更多指令级说明见[实现与验证](../../v480/README.md)。

## English

**On the ordinary Wi-Off main screen, turn the dial directly to change TTL FEC or manual power.** The patch reuses factory parameter routines, limits, 0.1 / 0.3 manual step selection and acceleration paths. A direct event is not consumed again as GUI navigation.

Menus, MODE, ZOOM, Sender, Receiver, locks, drawers and modals keep their original routes. **This revision does not include RX direct adjustment, SU-1 support or added SUB controls.** v2 addresses duplicate input consumption and the interrupt window between checking state and writing a parameter. It preserves/restores PRIMASK and the original selector without replacing the radio protocol.

The identities and offline results above apply to the exact V480F V1.03 sample. The maintainer reports flashing modified firmware, but did not supply an installed hash or complete acceptance matrix. Observed masked instruction counts and stack use are model bounds, not measured RF latency or whole-device stack guarantees. Historical dual-model totals remain separate.
