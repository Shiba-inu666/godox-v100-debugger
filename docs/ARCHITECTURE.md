# 调试工具结构与实现范围

本文仅描述电脑端工作台。原生固件补丁另见 [原生架构](native/ARCHITECTURE.md)。

## 执行链路

浏览器 → 仅监听 `127.0.0.1` 的 Python 服务 → 多模式状态适配 → Unicorn ARM Thumb 执行引擎 → 本地原始 V100F V1.03 固件。

- `debug/server.py`：静态页面、状态 API、带会话 token 的操作 API 和动作列表保存。
- `debug/device_engine.py`：Wi-Off / Sender / Receiver、Multi、MENU 和离线接收参数注入。
- `debug/engine.py`：Sender、SUB、原始组索引、撤销与回放。
- `debug/stock_vm.py`：固件校验、模拟内存、限定机器码入口、GUI 与传输调用替身。
- `debug/formatters.py`：执行原厂功率、FEC、ZOOM 显示函数，捕获文本输出。
- `debug/index.html`、`app.js`、`style.css`：电脑界面、旋钮/键盘适配、操作轨迹与内存监视。

程序没有运行完整 RTOS、LCD 或 MCU 外设模型。GUI 对象和页面生命周期由电脑提供。每次受限调用检查返回地址、栈指针与被调用者保存寄存器；请勿使用 Python `-O`。

## 主要原厂入口

| 地址 | 用途 |
|---|---|
| `0x08010924` / `0x0800BA84` | 当前 selector 的参数增减 |
| `0x0801BBE8` / `0x0801BF44` | Sender 事件及清理 |
| `0x0801A490` / `0x0801A924` | SUB 编辑及开关 |
| `0x0801C18C` / `0x0801C350` | Receiver 事件及清理 |
| `0x0801D972` | Multi 功率整档调节 |
| `0x08017C80` | Receiver 参数解析和目标地址过滤 |
| `0x0801249C` / `0x0801EFC4` / `0x0800C3D4` | 功率、FEC、ZOOM 显示 |
| `0x080184D4` | Sender 无线差异编码，传输由模拟器捕获 |
| `0x0800B7C0` | 序列化 79 字节设置记录到模拟 RAM |

Receiver 参数注入只接受模式、M 功率、Multi 功率、次数和频率。没有触发闪光命令、USB、串口或射频硬件端点。真实接收 ISR / FIFO 链路未运行。

## 状态与身份

- 原始 Sender M/A/B/C/D 索引为 0..4。SUB 是单独的本地副灯，视觉上插入列表，不占用无线组索引。
- Receiver 支持 A–E，组槽为 1..5，地址为 10..14。
- Wi-Off / Sender / Receiver 的页面字段为 0 / 1 / 2，角色字段为 0 / 3 / 4。页面切换由电脑适配。
- Multi 通过已确认 selector 调节功率、次数与频率。亮度、语言、待机等菜单值只写入模拟状态，不驱动实际行为。
- 初始状态是可重复的测试场景，不代表原厂出厂默认值。

## 会话与验证

会话保存动作列表，不接受任意内存镜像。恢复时在新引擎中执行完整动作列表，全部成功才替换当前状态。支持 schema 2 / 3，并要求固件哈希匹配。撤销、重做与导入回放共用执行路径。

26 项本地自动测试覆盖模式与边界、组隔离、接收地址过滤、菜单、会话兼容与 HTTP 保存恢复；测试需要本地原厂固件。界面另外验证过 Wi-Off 的单一 SUB 入口，以及 Receiver 左上选组、左下模式和右下变焦。

真实六行 GUI 对象分配、MCU 页面回调替换、固件补丁注入、硬件时序和热保护没有通过此工具得到验证。
